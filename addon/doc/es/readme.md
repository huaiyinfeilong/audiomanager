# Audio Manager

## Resumen de las características del complemento

El complemento NVDA Audio Manager está diseñado para ayudarte a gestionar múltiples dispositivos de audio y optimizar el enrutamiento de sonido de manera eficaz.

Las funcionalidades de este complemento se pueden categorizar en cuatro módulos principales:

- **Gestión de dispositivos de reproducción**: Este módulo permite ajustar el volumen, establecer el dispositivo de reproducción predeterminado del sistema y alternar entre silenciar y reactivar el sonido.
- **Gestión de dispositivos de grabación**: De manera similar a la gestión de dispositivos de reproducción, permite controlar el volumen, establecer el dispositivo de grabación predeterminado del sistema y silenciar/reactivar el sonido.
- **Control de audio específico por aplicación**: Esta función facilita la personalización de los dispositivos de reproducción y grabación, la modificación del volumen y el silenciado/reactivación de sonido para aplicaciones de audio individuales.
- **Funcionalidades adicionales**: Junto con las funciones mencionadas anteriormente, incluye varias características prácticas como el bloqueo del volumen del micrófono, el cambio de dispositivo de salida de NVDA, etc.
